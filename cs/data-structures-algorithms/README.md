## 1. 시간 복잡도와 공간 복잡도

### Big-O 표기법
알고리즘의 최악의 경우 성능을 나타냅니다.

| 표기법 | 이름 | 예시 |
|--------|------|------|
| O(1) | 상수 | 배열 인덱스 접근 |
| O(log n) | 로그 | 이진 탐색 |
| O(n) | 선형 | 배열 순회 |
| O(n log n) | 로그 선형 | 병합 정렬, 퀵 정렬 |
| O(n²) | 이차 | 이중 반복문 |
| O(2ⁿ) | 지수 | 피보나치 (재귀) |
| O(n!) | 팩토리얼 | 순열 생성 |

### 성능 비교
```
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)
```

## 2. 기본 자료구조

### 배열 (Array)
- **특징**: 고정 크기, 인덱스로 접근
- **시간 복잡도**:
  - 접근: O(1)
  - 탐색: O(n)
  - 삽입/삭제: O(n)

### 연결 리스트 (Linked List)
- **특징**: 동적 크기, 노드 연결
- **종류**: 단일, 이중, 원형
- **시간 복잡도**:
  - 접근: O(n)
  - 탐색: O(n)
  - 삽입/삭제: O(1) (노드 위치를 알 때)

### 스택 (Stack)
- **특징**: LIFO (Last In, First Out)
- **연산**: push, pop, peek
- **용도**: 함수 호출, 괄호 검사, DFS

### 큐 (Queue)
- **특징**: FIFO (First In, First Out)
- **연산**: enqueue, dequeue, peek
- **용도**: BFS, 작업 스케줄링

### 덱 (Deque)
- **특징**: 양쪽에서 삽입/삭제 가능
- **용도**: 슬라이딩 윈도우

### 해시 테이블 (Hash Table)
- **특징**: 키-값 쌍 저장
- **시간 복잡도**:
  - 평균: O(1)
  - 최악: O(n) (충돌 시)
- **충돌 해결**:
  - Chaining (연결 리스트)
  - Open Addressing (선형 탐사, 이차 탐사, 이중 해싱)

## 3. 트리와 그래프

### 이진 트리 (Binary Tree)
- **특징**: 각 노드가 최대 2개의 자식
- **종류**:
  - 완전 이진 트리 (Complete)
  - 포화 이진 트리 (Perfect)
  - 균형 이진 트리 (Balanced)

### 이진 탐색 트리 (BST)
- **특징**: 왼쪽 < 루트 < 오른쪽
- **시간 복잡도**:
  - 평균: O(log n)
  - 최악: O(n) (편향 트리)

### 트리 순회
- **전위 순회 (Preorder)**: 루트 → 왼쪽 → 오른쪽
- **중위 순회 (Inorder)**: 왼쪽 → 루트 → 오른쪽
- **후위 순회 (Postorder)**: 왼쪽 → 오른쪽 → 루트
- **레벨 순회 (Level-order)**: BFS

### 균형 트리
- **AVL 트리**: 높이 차이 최대 1
- **Red-Black 트리**: 균형 유지 규칙
- **B-트리**: 데이터베이스 인덱스

### 힙 (Heap)
- **특징**: 완전 이진 트리
- **종류**:
  - Max Heap: 부모 ≥ 자식
  - Min Heap: 부모 ≤ 자식
- **용도**: 우선순위 큐
- **시간 복잡도**:
  - 삽입: O(log n)
  - 삭제: O(log n)
  - 최소/최대 조회: O(1)

### 그래프 (Graph)
- **표현 방법**:
  - 인접 행렬 (Adjacency Matrix): O(V²) 공간
  - 인접 리스트 (Adjacency List): O(V + E) 공간
- **종류**:
  - 방향/무방향 그래프
  - 가중치/비가중치 그래프
  - 순환/비순환 그래프 (DAG)

## 4. 정렬과 탐색

### 정렬 알고리즘

| 알고리즘 | 시간 복잡도 (평균) | 시간 복잡도 (최악) | 공간 복잡도 | 안정성 |
|----------|---------------------|---------------------|-------------|--------|
| 버블 정렬 | O(n²) | O(n²) | O(1) | O |
| 선택 정렬 | O(n²) | O(n²) | O(1) | X |
| 삽입 정렬 | O(n²) | O(n²) | O(1) | O |
| 병합 정렬 | O(n log n) | O(n log n) | O(n) | O |
| 퀵 정렬 | O(n log n) | O(n²) | O(log n) | X |
| 힙 정렬 | O(n log n) | O(n log n) | O(1) | X |

### 탐색 알고리즘
- **선형 탐색**: O(n)
- **이진 탐색**: O(log n) - 정렬된 배열 필요
- **DFS (깊이 우선 탐색)**: O(V + E)
- **BFS (너비 우선 탐색)**: O(V + E)

## 5. 알고리즘 패턴

### 투 포인터 (Two Pointers)
- 배열의 양 끝 또는 같은 방향에서 이동
- **예**: 두 수의 합, 회문 검사

### 슬라이딩 윈도우 (Sliding Window)
- 고정/가변 크기의 윈도우를 이동하며 계산
- **예**: 최대 부분 배열 합

### 동적 계획법 (Dynamic Programming)
- 큰 문제를 작은 문제로 분할
- 중복 계산 방지 (메모이제이션)
- **예**: 피보나치, 배낭 문제, 최장 공통 부분 수열

### 그리디 (Greedy)
- 각 단계에서 최선의 선택
- **예**: 최소 신장 트리 (Kruskal, Prim), 동전 거스름돈

### 백트래킹 (Backtracking)
- 가능한 모든 경우를 탐색
- 조건에 맞지 않으면 되돌아감
- **예**: N-Queen, 스도쿠

### 분할 정복 (Divide and Conquer)
- 문제를 작은 부분으로 나누어 해결
- **예**: 병합 정렬, 퀵 정렬, 이진 탐색

## 그래프 알고리즘

### 최단 경로
- **다익스트라 (Dijkstra)**: O((V + E) log V) - 음수 간선 불가
- **벨만-포드 (Bellman-Ford)**: O(VE) - 음수 간선 가능
- **플로이드-워셜 (Floyd-Warshall)**: O(V³) - 모든 쌍 최단 경로

### 최소 신장 트리 (MST)
- **크루스칼 (Kruskal)**: O(E log E) - 간선 기준
- **프림 (Prim)**: O((V + E) log V) - 정점 기준

### 위상 정렬 (Topological Sort)
- DAG의 정점을 선형 순서로 나열
- **방법**: DFS, 진입 차수 이용
